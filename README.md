# Festive Christmas Calculator

A fully functional calculator with a beautiful Christmas theme, featuring:

- A looping Christmas video background
- Falling snow animation
- Adjustable background dimmer
- Festive button sounds using Web Audio API
- Keyboard support
- Responsive design

## Features

- **Video Background**: Plays a Christmas video (`xmas.mp4`) full-screen.
- **Snowfall Effect**: 48 animated snowflakes falling gently.
- **Sound Effects**: Different tones for numbers, operators, clear/delete, and equals.
- **Dim Control**: Slider to adjust darkness overlay (0–90%).
- **Responsive**: Works on mobile and desktop.
- **Keyboard Support**: Use your keyboard to type numbers and operations.

## Files

- `index.html` – Main structure
- `style.css` – All styling
- `script.js` – Calculator logic, sound, snow, and overlay controls
- `xmas.mp4` – **Required** video file (must be placed in the same folder)

## How to Use

1. Download or create all four files in the same directory:
   - `index.html`
   - `style.css`
   - `script.js`
   - `xmas.mp4` (any Christmas-themed looping video in MP4 format)

2. Open `index.html` in a modern browser (Chrome, Firefox, Edge, Safari).

3. Enjoy calculating with holiday spirit!

## Notes

- The video file (`xmas.mp4`) is **not included** — you need to provide your own looping Christmas video.
- Sound effects require user interaction first (click/touch) due to browser autoplay policies.
- No external dependencies or fonts are used (except system fonts).
